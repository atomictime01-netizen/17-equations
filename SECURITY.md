# Security policy

17 Equations runs entirely in the browser and makes no network calls at run time, so the
attack surface is small. If you still find a vulnerability (for example in the build or in a
dependency we ship), please report it privately.

**How to report:** use GitHub's private reporting on this repository
(**Security → Report a vulnerability**). Please do not open a public issue for it.

Include what you found, how to reproduce it, and the version or commit. You can expect an
acknowledgement within about a week. This is a volunteer project, so fixes are best-effort.

Only the latest release on the default branch is supported.
